# Python Swirl: estatística se aprende investigando

**Lançamento público da versão 0.1 · 7 de outubro de 2026**

Uma média parece resumir tudo. Mas o que acontece quando um único valor muda? Duas turmas podem ter a mesma média e realidades diferentes? Uma amostra conta toda a história?

O **Python Swirl** começa com essas perguntas. É um curso interativo gratuito, idealizado e dirigido pedagogicamente por **[Sidiney Rodrigues](https://github.com/sidineyr)**, para compreender estatística enquanto se pratica em Python.

Você prevê um resultado, executa um cálculo, observa o que aconteceu e explica o significado. Cada lição oferece dicas progressivas e um novo conjunto de dados para testar sua compreensão. Os dados desta versão são simulados.

## Disponível agora

- **O que uma média esconde?** Média, mediana e valores extremos.
- **Duas turmas, a mesma média. São iguais?** Dispersão, gráficos e limites de uma conclusão.
- **Uma amostra conta toda a história?** Sorteios, variabilidade e viés.

O curso roda no console Python, sem cadastro ou API paga. Salva o progresso localmente e aceita diferentes maneiras de calcular. Respostas abertas têm critérios de autoavaliação.

Para começar, baixe ou clone o [repositório](https://github.com/sidineyr/python-swirl-statistics), abra o terminal na pasta do projeto e execute:

```powershell
py -3 -m python_swirl
```

No Linux, use `python3 -m python_swirl`. Requer Python 3.10 ou superior. Veja [instalação](INSTALACAO.md).
