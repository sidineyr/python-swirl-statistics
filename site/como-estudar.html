Como estudar e executar Python

Em cada aula: problema → conceitos → vídeo → prática → questões → desafio → síntese. O vídeo é opcional; a prática de código é parte da entrega.

Com Google Colab

  1. Abra o notebook pelo botão da aula. O endereço aponta para um arquivo deste repositório.
  2. Entre na sua conta Google se o Colab solicitar. Para guardar trabalho, use Arquivo → Salvar uma cópia no Drive. O curso não recebe suas credenciais.
  3. Conecte ao ambiente de execução e execute as células em ordem, com Shift+Enter. Se pandas ou matplotlib não estiverem disponíveis, instale-os em uma célula com %pip install pandas matplotlib.
  4. Edite as células de prática e escreva a interpretação. Baixe seu .ipynb para guardar uma cópia.
  5. Volte à aba do Python Swirl, confira resultados e use a rubrica. Não há sincronização automática entre Colab e site.

Sem conta: Jupyter no computador

Instale Python 3.10 ou superior. No terminal, execute:

python -m pip install jupyterlab pandas matplotlib
python -m jupyterlab

No Windows, se python não for encontrado, substitua por py -3. Baixe o notebook na aula e abra-o no JupyterLab. O CSV já está incorporado ao notebook para não depender de download externo durante o estudo. Bibliotecas e instalação inicial exigem internet; depois os notebooks podem executar localmente.

Quando aparecer um erro

  • SyntaxError: confira parênteses, aspas, dois-pontos e indentação.
  • NameError: execute a célula que define o nome e confira a grafia.
  • ModuleNotFoundError: instale a biblioteca no mesmo ambiente do notebook.
  • Resultado diferente: revise dados, filtro, ausências e denominador. Use pistas graduais.

Salvar e retomar

O site salva textos, conferências e rubricas neste navegador. Se o armazenamento estiver bloqueado, avisará que a sessão não ficará salva. Exporte respostas na página inicial antes de trocar de dispositivo ou limpar o navegador. Importar uma exportação une os registros; conflitos da mesma aula preservam ambos os textos e pedem nova autoavaliação.

Limites da avaliação

O site confere números, não executa código nem interpreta automaticamente textos. O notebook executa Python real. A rubrica orienta autoavaliação. Não há evidência de eficácia educacional por piloto com estudantes.
