Faça o curso no seu computador

Requisitos: computador com Python 3.10 ou superior e terminal. O curso usa a biblioteca padrão, sem instalar dependências extras.

  1. Baixe o projeto em ZIP no GitHub. É o código atual da branch main, não um instalador.
  2. Localize o ZIP em Downloads e extraia-o. Abra a pasta python-swirl-statistics-main que contém README.md, pyproject.toml e a pasta python_swirl. Não execute de dentro do ZIP.
  3. Abra o terminal nessa pasta e use os comandos abaixo. Escolha a lição 1.

Windows

Se necessário, instale Python pelo site oficial. No Explorador de Arquivos, abra a pasta extraída. Clique na barra de endereço, digite powershell e pressione Enter. Na janela que abrir:

py -3 --version
py -3 -m python_swirl

O primeiro comando deve informar versão 3.10 ou superior. Se py não for reconhecido, verifique a instalação; quando python --version informar uma versão compatível, pode usar python -m python_swirl.

Linux

Abra a pasta extraída no gerenciador de arquivos e escolha “Abrir no terminal”, quando disponível. Alternativamente, abra o terminal e use cd com o caminho da pasta:

cd ~/Downloads/python-swirl-statistics-main
python3 --version
python3 -m python_swirl

Se Python estiver ausente ou for anterior a 3.10, instale uma versão compatível pelos canais da sua distribuição. Ajuste o caminho de Downloads se seu sistema usar outro nome.

Se algo não funcionar

  • No module named python_swirl: confirme que o terminal está na pasta que contém python_swirl, junto ao README.
  • Erro de escrita do código: use :dica. Dados alterados: :restaurar recupera o contexto sem apagar respostas.
  • :sair pausa; abra novamente e escolha a mesma lição. :revisar mostra suas explicações.

Linux foi verificado localmente; Linux e Windows têm testes técnicos em CI. Os passos visuais em Windows pessoal, macOS e leitores de tela ainda precisam de verificação. Consulte o alcance dos testes.

Código digitado executa localmente, com os privilégios do usuário, sem isolamento. A retomada pode repetir códigos registrados. Use código e lições de confiança. Respostas ficam no seu computador.
