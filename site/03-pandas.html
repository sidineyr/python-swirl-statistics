1. Investigue um problema

Uma tabela de estudantes contém turma, horas de estudo e nota. Como selecionar as linhas da turma A?

2. Entenda os conceitos

pandas é uma biblioteca para trabalhar com dados tabulares. Um DataFrame possui linhas, colunas e um índice. Neste curso cada linha representa um estudante sintético; cada coluna representa uma característica. Uma Series representa uma coluna ou sequência indexada.

CSV é um arquivo de texto com campos separados por delimitadores. pd.read_csv lê o arquivo; separador e codificação precisam corresponder ao arquivo. head() permite olhar as primeiras linhas; shape informa (linhas, colunas); dtypes informa tipos usados pelo software, que não substituem a classificação estatística.

df["turma"] seleciona uma coluna. df["turma"] == "A" produz uma máscara booleana; df.loc[mascara] seleciona linhas verdadeiras. Este filtro muda o grupo analisado: uma média da turma A não é automaticamente a média de toda a tabela.

Exemplo resolvido em Python

import pandas as pd
from io import StringIO
df = pd.read_csv(StringIO("turma,nota\nA,6\nA,8\nB,10\n"))
print(df.shape)
print(df.loc[df["turma"] == "A", "nota"].mean())

A tabela tem três linhas e duas colunas. A média da turma A é 7. A turma B fica fora desse cálculo porque o filtro foi explícito.

Erros frequentes e limites

  • Um caminho de arquivo inexistente gera FileNotFoundError: confira pasta e nome.
  • Não conclua o tipo estatístico apenas pelo dtype.
  • A contagem de linhas não é sempre a contagem de pessoas únicas.

6. Resolva um desafio concreto

Leia o CSV fornecido no notebook. Inspecione shape, head e dtypes. Selecione a turma B e calcule a média de suas notas válidas, sem preencher valores ausentes.

Dados: exemplos e CSV sintéticos, criados para ensinar; não representam estudantes reais. A entrega inclui código executado e interpretação no notebook.

Pista 1: por onde começar

Pista 2: procedimento

mean ignora valores ausentes por padrão; declare isso.

Solução de referência e interpretação
print(df.shape)
print(df.head())
print(df.dtypes)
print(df.loc[df["turma"] == "B", "nota"].mean())

  • Filtro B seleciona o grupo correto.
  • Média de notas válidas é 7.2; menciona ausência e tamanho do grupo.
