Python Swirl — Aprenda estatística praticando em Python.

Um curso gratuito para quem está começando a analisar dados. O objetivo é entender o raciocínio estatístico, praticar e interpretar resultados.

Comece pelo repositório

O que você pode aprender agora

  • Média e mediana: como resumir dados e interpretar valores extremos.
  • Dispersão: como observar a variabilidade dos dados.
  • Amostragem: como pensar sobre a seleção de observações.

As três lições interativas são executadas no terminal do seu computador com Python 3.10 ou superior. Esta página apresenta o curso; a prática em Python acontece localmente.

Experimente uma ideia

Leia uma pequena lição sobre média e mediana e compare os resultados antes de calcular.

Como funciona

O curso oferece dicas, exploração, pausa e retomada. Consulte o guia de uso e a instalação no Windows e no Linux.

O projeto está na versão inicial 0.1. Não oferece certificação nem eficácia pedagógica comprovada. Veja o currículo e os planos futuros.
