Um curso gratuito idealizado pelo professor Sidiney Rodrigues. Dez módulos ligam conceitos, aulas em vídeo, prática guiada e desafios com novos dados.

Para iniciantes em programação e estatística. Você precisa de operações aritméticas básicas e acesso a um computador para os notebooks. Cerca de 12 horas de leitura e prática, além dos vídeos; seu ritmo pode variar.

O que você entrega

Ao final, um notebook com pergunta, dados, limpeza, medidas, gráficos e uma conclusão com limitações. Use dados sintéticos sem dados pessoais. Não há cadastro obrigatório no curso, API paga ou certificado.
