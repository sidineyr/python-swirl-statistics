2. Entenda os conceitos

Uma variável de programação é um nome associado a um objeto: tempos = [10, 20, 30] associa o nome tempos a uma lista. Uma variável estatística é uma característica observada, como tempo de estudo; cada estudante tem um valor dessa característica. Um nome Python pode guardar todos esses valores.

int representa inteiros, float números com parte decimal, str texto e bool valores lógicos. "10" é texto, enquanto 10 é número. int("10") converte esse texto em inteiro. Converter um identificador como "0012" para número pode perder informação e não é sempre apropriado.

Uma lista é uma sequência ordenada entre colchetes. A primeira posição tem índice 0: tempos[0]. len(tempos) conta elementos e sum(tempos) soma números. A média aritmética divide a soma pela quantidade; a lista precisa ter pelo menos um elemento.

Exemplo resolvido em Python

tempos = [10, 20, 30]
print(tempos[0])
print(sum(tempos) / len(tempos))
print(int("10") + 2)

As saídas são 10, 20.0 e 12. O resumo de 20 minutos não afirma que todos estudaram 20 minutos. A lista conserva diferenças que a média esconde.

Erros frequentes e limites

  • Usar tempos[1] para o primeiro valor seleciona o segundo.
  • "10" + "2" concatena texto e produz "102".
  • Somar números e dividir por uma quantidade fixa quebra o cálculo quando a lista muda.

5. Confira e interprete

A conferência aceita vírgula ou ponto decimal e tolerância de 0,01. Um resultado correto não comprova o método: registre o código no notebook.

Questão 1

Qual é o primeiro elemento de [5, 15, 25] usando o índice correto?

Preciso de uma pista

A contagem de posições começa em zero.

Ver solução comentada

5: O índice 0 acessa o primeiro elemento.

Questão 2

Complete sum(tempos) / ___ para [5, 15, 25]. Qual é a média?

Preciso de uma pista

São três valores, cuja soma é 45.

Ver solução comentada

15: Dividir por len(tempos) acompanha a quantidade de observações.

6. Resolva um desafio concreto

Para novos tempos [15, 25, 35, 45], escreva duas maneiras equivalentes de calcular a média. Explique por que média 30 não descreve cada pessoa.

Dados: exemplos e CSV sintéticos, criados para ensinar; não representam estudantes reais. A entrega inclui código executado e interpretação no notebook.

Pista 2: procedimento

Compare sum/len com statistics.mean.

Solução de referência e interpretação
tempos = [15, 25, 35, 45]
print(sum(tempos) / len(tempos))
from statistics import mean
print(mean(tempos))
  • Duas expressões retornam 30.
  • Tipos numéricos são usados.
  • Interpretação preserva diferenças individuais.
